Accessibility

  • Use <a> for navigation and <button> for actions.
  • Contrast: white on ink 19.8:1, ink on Grey 50 18.5:1, ink on lime 15.3:1 — all AAA.
  • The ↗ arrow is added with CSS ::after, so screen readers don’t announce it.
  • Target size is at least 44 × 44px.
  • The focus ring is ink with a white gap, so it shows on white, grey and lime.
  • Labels are verbs that say what happens (“View live site”), not “Click here”. Uppercase is done in CSS, so the source text stays readable.
  • The arrow animation is turned off under prefers-reduced-motion.
