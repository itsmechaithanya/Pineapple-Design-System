DM Sans

Low-contrast grotesque from Colophon, built for small sizes. A variable font (optical size + weight), so one file covers every body style.

Outfit carries over Hierarchy 3 from my type hierarchies assignment. See all three on the type hierarchy site.

Accessibility

  • Body never goes below 16px; 13px is only for captions and labels.
  • Light weights are only used at 40px and up, where thin strokes stay readable.
  • Brackets in labels are decorative — screen readers read “[ 01 ] Overview” fine, but section meaning comes from the real h2.
  • One h1 per page; heading levels are never skipped for visual size.
